Cubie for Mac

Cubie is invite-only for now. The app asks for the email you were invited with and sends it a code. To join a call someone sent you, the link is enough: it opens in your browser.

Mac

Alpha · Apple Silicon and Intel · macOS 12.3 or later (screen sharing needs macOS 14)

Apple Silicon (M1 and later) Intel

Not sure? Apple menu → About This Mac: “Chip: Apple M…” is Apple Silicon, “Processor: … Intel” is Intel.

  1. Unzip it and drag Cubie into Applications.
  2. Open Cubie from Applications. If macOS asks whether to open an app downloaded from the internet, click Open.

Install on a Mac using Terminal

curl -fsSL https://cubiecall.com/download/install.sh | sh

Puts Cubie in Applications and opens it. Cubie checks for updates automatically.

Permissions on a Mac

  • Microphone and camera: macOS asks the first time you use them.
  • Screen sharing: the first time you share, allow Cubie under System Settings → Privacy & Security → Screen & System Audio Recording, then quit and reopen Cubie.

Windows

Test build · Windows 10 and 11, 64-bit · not signed yet

Windows (64-bit)
  1. Unzip it (right-click → Extract All…) and open Cubie.exe.
  2. The build isn’t signed yet, so Windows may say “Windows protected your PC”. Click More info, then Run anyway.

Cubie doesn’t update itself on Windows yet: download it again for a newer version.

Something broke?

On a Mac, send the log: ~/Library/Logs/Cubie/cubie.log (in Finder: Go → Go to Folder…, paste the path).

On Windows: %LOCALAPPDATA%\Cubie\Logs\cubie.log (paste the path into File Explorer’s address bar).
